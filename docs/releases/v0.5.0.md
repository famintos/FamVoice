### Added

- FamVoice mark set vendored in-repo (amber, white, black, compact optical size, app icon), so CI and release builds no longer depend on a sibling checkout.
- The mark is now a live instrument in the widget: bars carry microphone level, lines carry the transcript, both drawn in user units so the two halves keep one stroke weight at any render size.
- Tray pipeline with vendored state frames (idle, recording, transcribing, success), driven by the dictation pipeline with throttled microphone level.

### Changed

- The widget no longer swaps components between idle and listening. It is one lockup with two ends: the wordmark collapses out of it and the mark grows into the space it leaves, cross-fading from the static mark to the live one. The word leads on the way out and trails on the way in, so it never appears before the pill has opened for it.
- Widget window sizing moved from the pill to an envelope spanning every widget state, so a state change no longer drags a window resize behind it. Hit testing and dragging still measure the visible pill, so the transparent margin around it stays click-through.
- The mark switches to its compact optical size at and below 32px, where the regular stroke renders under 2px and the mark smears.
- Desktop, Android, and iOS icon sets regenerated from the new mark; `build.rs` now rebuilds the binary when a tray frame is edited.

### Testing

- `npm test` — 98 source checks + 16 component tests pass.
- `tsc`, `eslint`, and `vite build` pass.
- The widget morph has not been watched running in the app; it is verified by source and layout review only.
