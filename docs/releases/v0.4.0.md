### Added

- Retry-last-dictation with a RAM-only, single-use audio cache.
- Diagnostics center: microphone test, device/hotkey/provider checks, sanitized diagnostics export.
- Encrypted v2 history with search, pins, export, and retention controls.
- History delete with undo.

### Changed

- `gpt-transcribe` is now the default transcription model, with automatic `whisper-1` fallback.
- Provider/model-aware multipart request fields, glossary-to-keywords mapping, SSE delta parsing, and duration-scaled request timeouts.
- Versioned settings migration.
- Dark theme locked explicitly across the app.
- History modal is now fully accessible: focus trap, focus restore, inert background.
- Hotkey capture is labeled and announced to assistive tech; recording/transcribing/success states use live regions.
- Minimum 24px touch targets; single-flight cursor polling; overshoot-free animation easing.

### Fixed

- Stale recording sessions can no longer clobber a newer session's state, history, or clipboard paste (monotonic session coordinator).
- Empty transcription responses are now rejected instead of silently accepted.
- Clipboard re-paste transactions are serialized to avoid races.
- Recovery from CPAL audio stream faults; microphone can no longer be switched mid-recording.
- History and settings writes are now atomic (temp file + fsync + replace).
- Keyring backend is injectable/testable with a DPAPI fallback authority.
- Delivery/injection text is capped at 10k characters, enforced on Windows.
- `cargo clippy` is now aligned between local dev, `ci.yml`, and `release.yml` (`--all-targets --all-features -D warnings`), guarded by a parity test.

### Testing

- Added a React 19 component test runner with typed Tauri mocks, a mock HTTP server (success/error/timeout/retry/SSE/empty), and a fault injection harness.
- Added a Windows native smoke test harness.
- `npm test` — 85 source checks + 16 component tests pass.
- `cargo test` — 191 tests pass; `cargo clippy --all-targets --all-features -- -D warnings` and `cargo audit` pass.
